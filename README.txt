LUCA AI – iPad-Pro-Version

WAS IST DAS?
Eine installierbare Web-App (PWA), optimiert für das iPad Pro:
- Vollbildmodus vom Home-Bildschirm
- Hoch- und Querformat
- Safe-Area für Displayränder
- große Touchflächen
- lokale PIN und lokale Chats
- Offline-Demo nach dem ersten Laden
- keine Kamera-, Mikrofon- oder Speicherberechtigungen

INSTALLATION AUF DEM IPAD
1. Den Ordner auf einen HTTPS-Webspace hochladen, z. B. GitHub Pages.
2. Die Webadresse in Safari öffnen.
3. Teilen → Zum Home-Bildschirm.
4. „Als Web-App öffnen“ aktivieren.
5. Hinzufügen.

WICHTIG
- Die enthaltenen Antworten sind lokale Demo-Antworten, noch keine echte Online-KI.
- PIN und Chats bleiben im Browser/Web-App-Speicher dieses Geräts.
- Die Datei LucaAI-iPad-Pro-Offline.html kann direkt getestet werden, ist aber ohne Webserver nicht als PWA installierbar.
